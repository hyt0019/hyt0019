# Hi, I'm hyt0019 👋

用代码解决实际问题，让复杂的信息更直观。

项目围绕实用工具、自动化、三维可视化和企业应用展开。从装箱规划、录像修复与选课辅助，到双语网站、业务管理系统和代码城市，把实际需求转化为易用、可维护的软件。

主要使用 Python 和 TypeScript，关注功能实现，也重视界面体验、使用文档和自动化测试。

## 🛠️ 我的项目

- **[loader](https://github.com/hyt0019/loader)**  
  三维装箱规划工具，结合真实装载约束与优化算法，提供交互式预览和方案导入导出。

- **[Code City](https://github.com/hyt0019/code-city)**  
  把代码仓库变成一座城市，生成 GitHub 主页横幅和交互式 3D 页面，让项目规模与结构变得可见。

- **[ReplayFlashFix](https://github.com/hyt0019/ReplayFlashFix)**  
  检测并清除 NVIDIA 即时重放录像中意外混入的桌面闪帧，支持 Windows 图形界面、本地处理和批量修复。

- **[TJU Course Watcher](https://github.com/hyt0019/TJU-auto-course-selector)**  
  基于 Python 标准库的天津大学选课辅助工具，支持满员重试、成功停止和登录失效提示。

- **双语企业展示网站 · 私有项目**  
  面向企业介绍与产品展示的中英双语网站，支持语言切换、产品分类和结构化内容维护。将内容与页面代码分离，方便日常更新，并支持容器化部署。

- **外贸业务协同系统 · 私有项目**  
  串联采购、分批发货、报关与开票流程，将分散的表格和人工核对整合为可追溯的业务流程。支持数据导入导出、账号权限和操作审计，提供 Web 与桌面端。
